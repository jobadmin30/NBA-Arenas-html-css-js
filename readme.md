# NBA Arenas

Site web vitrine présentant des arènes légendaires de la NBA, réalisé avec HTML, CSS et JavaScript.

## Aperçu

[Voir le site en ligne](https://TON-PSEUDO.github.io/NOM-DU-DEPOT/)

## Fonctionnalités

- Page d'accueil avec image de fond et formulaire de recherche (conférence, ville, état)
- Section **About** avec vidéo en boucle et animations d'entrée
- Section **Popular Destination** : cartes d'arènes avec effet au survol
- Section **Contact** avec formulaire et carte Google Maps intégrée
- Menu de navigation avec défilement fluide
- **Menu responsive** : un bouton burger s'affiche sur mobile et ouvre le menu (géré en JavaScript)
- Design adapté aux écrans mobiles (media queries)

## Technologies utilisées

- HTML5
- CSS3 (Flexbox, Grid, animations, media queries)
- JavaScript (manipulation du DOM)
- [Font Awesome](https://fontawesome.com/) pour les icônes
- Google Fonts (Raleway)

## Lancer le projet

1. Clone le dépôt :
   ```bash
   git clone https://github.com/TON-PSEUDO/NOM-DU-DEPOT.git
   ```
2. Ouvre le dossier dans VS Code.
3. Lance `index.html` avec l'extension **Live Server**, ou double-clique sur le fichier pour l'ouvrir dans ton navigateur.
